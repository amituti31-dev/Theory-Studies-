לימודי תיאוריה — יצירת קובץ AppImage ללינוקס (Ubuntu / Linux Mint)
==================================================================

המטרה: קובץ אחד בשם  LimudeiTeoria-x86_64.AppImage
שלוחצים עליו פעמיים והתוכנה רצה — בדיוק כמו ב-Windows.

צריך לבנות אותו פעם אחת על מחשב לינוקס. אחרי זה, הקובץ מוכן
ואפשר להעביר אותו לכל מחשב לינוקס.

איך בונים (פעם אחת)
-------------------
1. העבירו את התיקייה הזאת כולה למחשב הלינוקס.
2. לחצו ימני בתוך התיקייה -> "Open in Terminal" (פתח בטרמינל).
3. הדביקו את שתי הפקודות (אחת אחרי השנייה, Enter אחרי כל אחת):

       chmod +x build_linux.sh
       ./build_linux.sh

   (אם הוא מבקש סיסמה — זו הסיסמה של המשתמש שלכם בלינוקס.)
   בפעם הראשונה זה יכול לקחת 10-20 דקות.

4. בסיום — יופיע קובץ בשם:
       LimudeiTeoria-x86_64.AppImage

   לוחצים עליו פעמיים -> התוכנה נפתחת. זהו!
   (אם בלחיצה כפולה הוא לא רץ: לחצו ימני -> Properties -> Permissions ->
    סמנו V ליד "Allow executing file as program".)

מה עובד
-------
כמו בגרסת Windows — כל השאלות, המבחנים, התמונות, ההקראה הקולית
(דורשת אינטרנט), בורר המהירות, מצב לילה, וכל הרישיונות.

הערות
-----
• ההקראה משתמשת ב-python3 + edge-tts (הסקריפט מתקין אותם אוטומטית).
• צריך חיבור לאינטרנט להקראה בלבד.

דרישות
------
• Ubuntu 20.04+ או Linux Mint (או דיסטרו מבוסס Debian)
• חיבור לאינטרנט (להתקנה ולהקראה)

אם משהו נכשל בבנייה — העתיקו את הודעת השגיאה ושלחו לי, ואתקן.
